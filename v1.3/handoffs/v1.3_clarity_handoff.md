# v1.3 Clarity Handoff – Assistant Launch Pack

---

## ✅ Purpose of v1.3

v1.3 upgrades the Assistant Launch Pack from a modular interface to a real-time data-powered system. It introduces feedback loops, token tracking, audit reporting, and internal system observability — all within Streamlit.

---

## ✅ What Was Built

### New Tabs:
- `tab_feedback_log.py` — Captures and displays user/system feedback
- `tab_audit_viewer.py` — Shows version metadata, audit logs, feedback/tokens
- `tab_usage_log.py` — Displays recent assistant shortcut triggers

### New Core Modules:
- `token_tracker.py` — Logs GPT token usage per interaction
- `background_runner.py` — Timestamped daemon tasks for heartbeat/trigger chains
- `notion_sync.py` — Syncs logs to Notion via API

## ✅ How to Launch

```bash
source .venv/bin/activate
python run_ui.py
```

- Select a tab from dropdown
- Use `Feedback Log` to simulate user input
- Check `Audit Viewer` to verify logs
- Trigger assistant shortcuts to populate usage history
